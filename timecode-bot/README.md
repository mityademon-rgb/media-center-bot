# TIMECODE · бот медиацентра

Отдельный проект от КТ16: Telegram bot + яркое Mini App в визуальном стиле [TIMECODE](https://timecode-lab.ru/). Python 3.12+, SQLite, стандартная библиотека; один процесс для сайта, Telegram polling и ежедневного расписания. Часы — московское время.

## Эфир

| Москва | Выпуск |
| --- | --- |
| 07:30 | Личные вопросы: как спалось, как дела, что важного |
| 08:30 | Напоминание тем, кто не закончил отвечать |
| 09:00 | Закрытие утренних ответов |
| 10:00 | Общая сводка с разделами Kids Lab и Media Lab из полученных ответов |
| 15:00 | Новый короткий лайфхак с источником; при сбое — приём из редакционного банка |
| 18:00 | Личные вечерние вопросы: как прошёл день, яркий момент, доволен ли днём |
| 19:00 | Напоминание тем, кто не закончил отвечать |
| 20:00 | Закрытие вечерних ответов |
| 20:30 | Общая вечерняя сводка с разделами Kids Lab и Media Lab |
| Пн, ср 16:00 | Микро задания с двумя возрастными версиями: одно фото или короткая фраза |
| Вт, пт 16:00 | Мгновенное фото: сфоткай то, что сейчас перед тобой |
| Вт, пт 20:30 | Подборка мгновенных кадров после вечерней сводки |
| Вс 18:00 | Титры недели по добровольному участию |

Если ответов нет, бот сообщает, что выпуск сегодня без ответов. Kimi выбирает тему и через собственный Web Search Pro ищет профильные материалы Frame.io, StudioBinder, No Film School, B&H, Poynter, а в отдельные дни — публичные материалы киноавторов на YouTube/Aputure. На основе найденного фрагмента формулирует лайфхак и даёт ссылку на конкретный источник. Это поиск по **публично доступным страницам**, а не прямое чтение закрытой ленты соцсетей. Kimi сам придумывает новые задания, сводки из присланных ответов и недельные титры. Нужен сетевой доступ сервера к `api.moonshot.ai`; при ошибке API выходят редакционные шаблоны. Сгенерированные задания и лайфхаки сохраняются в SQLite, поэтому в чате и приложении один выпуск. Полностью автоматический поиск и сочинение могут давать ошибки или неудачные шутки: первые выпуски стоит проверить. Фото подборки собираются автоматически из присланных на мгновенное задание снимков. Участникам нужно заранее объяснить: не присылать кадры с другими людьми без разрешения. Автоматическая публикация не обеспечивает проверку сюжета фотографии человеком. Оригиналы фото остаются у Telegram: в базе только `file_id`; бот репостит альбом через Telegram API.

Направление задания выбирается по циклу: один кадр, вопрос, выбор решения, кадр без лиц, заголовок, звук. Kimi получает это направление и предлагает две короткие формулировки общей идеи: для Kids Lab (12–13 лет) и Media Lab (14–17 лет). В общем чате видны обе версии, в Mini App — только версия лаборатории ученика. Формат ответа чередуется принудительно, так что Kimi не сможет каждый раз просить фотографию. Для визуальных заданий первая версия использует карточки интерфейса и заранее подготовленные иллюстрации: в документации [Kimi API](https://platform.kimi.ai/docs/overview) описан приём изображений на вход, но генерация новых картинок через этот API пока не подтверждена. Отдельный сервис иллюстраций можно добавить после проверки его API, не меняя расписание заданий.

Из ответов учеников Kimi получает **только тексты завершённых перекличек**, чтобы составить общую сводку. Личные вопросы учеников преподавателю Kimi не получает. Для работы с несовершеннолетними нужно заранее объяснить участникам и их представителям, какие данные уходят провайдеру модели, и получить необходимые разрешения по выбранному порядку медиацентра. Можно оставить `MOONSHOT_API_KEY` пустым: продукт работает с редакционными шаблонами.

В приложении: расписание обеих лабораторий, отмены и замены, тест «Кто ты в кино?», игры «Какой кадр первый?», «Вопрос, который работает», «Два кадра — найди отличия» и ссылка на уроки сайта TIMECODE. Ответы тестов сохраняются в личном профиле. Игры не отправляют результаты в общий чат.

## Запуск локально

```bash
cd timecode-bot
cp .env.example .env
python3 - <<'PY'
import secrets
print('SECRET='+secrets.token_urlsafe(48))
print('JOIN_SECRET='+secrets.token_urlsafe(24))
PY
```

Скопируйте значения в `.env`. Для локальной проверки достаточно `SECRET` и `PORT`, `BOT_TOKEN` оставить пустым. Затем:

```bash
set -a; . ./.env; set +a
python3 server.py
```

Проверка: `curl http://127.0.0.1:8097/health`. Локально без Telegram открывается только экран входа; вход для пользователей работает после настройки бота.

## Для реального запуска

Для существующего сервера TIMECODE подготовлен однократный установщик `deploy/install-on-timecode-domain.sh`: размещает Mini App по `https://timecode-lab.ru/tc/` на действующем HTTPS, при этом добавляет только два маршрута `/tc` и `/tc/` в проверенный vhost `boom-kadr.conf`. Перед редактированием сохраняет резервную копию конфига, проверяет `nginx -t` и откатывает его при ошибке. Вводит токен нового бота и ключ Kimi скрыто прямо в терминале сервера; в репозитории ключей нет. Не включать повторно на уже установленной машине. После установки бот самостоятельно включает кнопку «Открыть TIMECODE» в своём меню.

1. Создать **нового отдельного бота** через @BotFather. Записать `BOT_TOKEN`, `ADMIN_IDS` (числовые ID преподавателей) и случайный `JOIN_SECRET` длиной от 20 символов в приватный env-файл. Не присылать токены в общий чат и не класть env в GitHub.
2. Назначить боту постоянный HTTPS адрес `BASE_URL`. На действующем сервере установщик использует `https://timecode-lab.ru/tc/`; для нового hostname подключить Nginx к `127.0.0.1:8097` по примеру `deploy/nginx.example.conf` с собственным сертификатом. Добавить бота в общий чат с правом публиковать сообщения и написать там от своего аккаунта <code>/connect</code>. Бот сам запомнит ID чата в базе. `PUBLIC_CHAT_ID` можно оставить пустым. Не использовать адрес, который смотрит на старый IP 72.56.65.161.
3. Запустить **один** экземпляр `server.py` с env-файлом. Пример unit-файла для VPS — `deploy/timecode-bot.service`: разместить код в `/opt/timecode-bot`, секреты в `/etc/timecode-bot.env`, базу в `/var/lib/timecode-bot/timecode.db` (права записи у `www-data`). Второй экземпляр создаст дубли Telegram polling. При старте без HTTPS адреса, защищённого приглашения и администратора бот откажется работать.
4. Преподаватель отправляет боту `/start` и `/invite`, затем раздаёт ученикам ссылку приглашения. Ученик начинает чат с ботом, выбирает лабораторию в профиле приложения либо `/lab kids` или `/lab media`.
5. Расписание заполняется в приложении «Моё» → «Режим редактора», либо командами `/schedule`, `/lesson`, `/change`, `/cancel`. Занятия напоминаются примерно за 1 час 40 минут до начала. Команда `/send текст` публикует объявление в общем чате. Вход в браузере — `/login`, код действует 5 минут.

## Управление через личный чат с ботом

- После `/start` преподавателю доступны кнопки **«Написать всем»** и **«Вопросы»**. Нажал первую — отправь боту следующий текст, фото, видео или документ; он опубликует в общем чате. `/stop` отменит режим отправки.
- `/send Текст` — быстрая публикация без кнопок. Фото, видео и документ с подписью `/send Текст` публикуются вместе с подписью. Бот использует Telegram `file_id` и не хранит эти файлы на сервере.
- Ученик задаёт вопрос боту обычным сообщением или `/ask Вопрос` — в личном либо в общем чате. Для вопроса в общем чате ученик должен уже открыть приглашение бота. Преподавателю приходит карточка «Вопрос #…». Нажми **«Ответить ученику»** и пришли ответ текстом или файлом. Также можно **ответить прямо на сообщение с вопросом** в Telegram или написать `/reply 12 Текст ответа`. Ответ придёт ученику лично.
- `/help` — краткая памятка, `/schedule` — команды расписания, `/invite` — пригласительная ссылка. `/connect` один раз в общем чате связывает его с ботом.
- `/ai off` — прекратить создание новых экспериментальных лайфхаков и заданий Kimi, вернуться к редакционному банку. `/ai on` — включить снова; `/ai` — показать состояние. Личные сводки остаются на обычном режиме Kimi, если ключ настроен.

Ответы завершённой переклички входят в сводку без дополнительных кнопок; отправленный на мгновенное задание кадр входит в вечернюю подборку. Можно не отвечать и не отправлять фото. Личные переклички отключаются командой `/quiet` или в профиле и возвращаются через `/live`. Сообщения чата бот не читает, всё взаимодействие происходит в личной переписке с ботом и внутри Mini App.

## Ограничения первой версии

- Банк из 14 проверенных приёмов и 7 чередующихся заданий — запасной режим. При подключённом ключе Kimi ищет материалы на перечисленных профильных сайтах и в открытых видео сообществах. Поиск может не извлечь содержимое страницы, если она закрыта регистрацией или блокирует индексирование; в таком случае выходит приём из банка.
- Напоминания основаны на постоянном недельном расписании; замена задана на дату и лабораторию. Панель умеет добавлять записи, удаление записей и история изменений пока только через SQLite/команды администратора.
- Фото материалы публикуются автоматически при согласии автора; распознавания лиц и надёжной автоматической модерации изображений в этой версии нет.
- Для нескольких десятков учеников SQLite и процесс на небольшом VPS достаточны; видео в эту версию не загружается, чтобы не заполнять сервер.
