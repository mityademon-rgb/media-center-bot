# КИНО / ГРУППА

Telegram бот и адаптивное мини-приложение для учебной группы. Python 3.12+, SQLite, без внешних пакетов. Работает по HTTPS за Nginx. Один процесс держит сайт и получает сообщения бота через long polling.

## Первая настройка

1. Создайте бота в @BotFather, сохраните токен. Напишите ему `/start` со своего аккаунта; свой числовой Telegram ID узнайте, например, через @userinfobot. Добавьте ID старосты и резервного администратора в `ADMIN_IDS` через запятую.
2. Сделайте закрытый репозиторий GitHub и загрузите код. Не публикуйте `.env`, `data/` и `uploads/`; они исключены из Git.
3. На сервере: `git clone ...; cd kino-group; cp .env.example .env; nano .env`. Впишите токен, ID, домен и название. Запуск: `set -a; . ./.env; set +a; python3 server.py`. Для постоянной работы используйте systemd/pm2. Один экземпляр процесса, чтобы не было двух polling циклов.
4. Направьте домен с HTTPS через Nginx на `http://127.0.0.1:8080`. В @BotFather укажите HTTPS URL мини-приложения через `/setmenubutton` (и при желании Main Mini App).
5. Староста заходит по кнопке бота или через браузер: `/login` в личном чате с ботом → код в форме входа. Студенты нажимают `/start`, затем открывают приложение. Только пользователи, начавшие чат с ботом, получат личную рассылку.

Пример блока Nginx внутри HTTPS server: `location / { proxy_pass http://127.0.0.1:8080; proxy_set_header Host $host; proxy_set_header X-Forwarded-Proto https; client_max_body_size 21m; }`.

### Администрирование из бота

`/send Текст` — объявление всем. Документ с подписью `/send Текст` — объявление с вложением. `/mute` отключает уведомления для своего аккаунта, `/start` включает снова. В веб-панели есть расписание, замены, преподаватели, полезные ссылки и публикации с файлами.

### Данные и резервная копия

Копируйте `data/group.db` и `uploads/` вместе, желательно после остановки процесса или SQLite backup API. Файлы доступны только авторизованным участникам. Телефон участника показывается только после его явного согласия в профиле. Максимальный размер вложения 20 МБ. Рассылка сохраняет статус доставки по каждому адресату в таблице `deliveries`; заблокировавшие бота не получат сообщение.

Для первой версии проект рассчитан на одну учебную группу. При объединении нескольких групп потребуется добавить членство и разделение рассылок.
